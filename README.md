
# 🌿 Root & Bloom

A simple, responsive plant shop website built using HTML and Tailwind CSS.

## Features
- Home page
- Product page with search bar design
- Contact page with contact form
- about page with about us information
- Responsive layout for mobile and desktop
- Font Awesome icons

## Technologies Used
- HTML5
- Tailwind CSS
- Font Awesome

## Pages
- `index.html` – Home page
- `product.html` – Products page
- `about.html` – About page
- `contact.html` – Contact page

## How to Run
1. Download or clone this repository.
2. Open `index.html` in your browser.

## Author
Created as an HTML and Tailwind CSS practice project.
Mobile Navigation

## mobile view navigation instruction
On mobile view, please use the navigation links available in the footer menu to access the Home, Products, About, and Contact pages. The top navigation menu is designed differently for mobile screens.
